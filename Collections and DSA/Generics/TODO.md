# Generics (Type Safety & Wildcards) - Code Demos

## What’s inside
This folder contains Java demos showcasing the generics best-practices:
1. Use Generics to Ensure Type Safety
2. Prefer Generic Methods Over Overloading
3. Use Upper Bounded Wildcards (`? extends T`) for Read-Only Access
4. Use Lower Bounded Wildcards (`? super T`) for Write Operations
5. Avoid Raw Types
6. Use Bounded Type Parameters (`<T extends ...>`)
7. Favor Generic Interfaces for Common Behaviors
8. Minimize Wildcard Usage in Public APIs
9. Combine Generics with Functional Interfaces and Streams
10. Use Generic Constructors Where Necessary

## Run instructions
Compile from project root:
- `javac "Collections and DSA/Generics"/*.java`

Run any demo (example):
- `java -cp . "Collections and DSA/Generics"/GenericsTypeSafetyDemo`

> Note: folder names with spaces may require quoting in your terminal/IDE.
