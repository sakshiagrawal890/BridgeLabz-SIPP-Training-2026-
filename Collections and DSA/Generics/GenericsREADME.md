# Generics (Demos)

Location: `Collections and DSA/Generics/`

## Compile
From repo root:
- `javac "Collections and DSA/Generics"/*.java`

## Run
Each file contains a `main` method. Example:
- `java -cp . "Collections and DSA/Generics/GenericsTypeSafetyDemo"`

## Notes
- These examples intentionally demonstrate generics best practices (type safety, wildcard usage, bounded type parameters, generic methods, generic interfaces, functional interfaces, etc.).
- Folder/package names in these demos are left **unpackaged** (no `package ...;`) to avoid build-path issues in this repository.
