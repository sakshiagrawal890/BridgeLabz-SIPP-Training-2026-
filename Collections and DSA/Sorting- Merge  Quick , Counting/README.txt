Sorting practice implementations:

1. MergeSortLibraryBooks.java - Merge Sort with empirical runtime for sizes 100, 1000, 10000.
2. MergeSortEmployeeSalaries.java - Merge Sort for employee salaries, input/output for practice problem.
3. MergeSortCustomerOrderValues.java - Merge Sort for customer order values.
4. MergeSortPatientRegistrationIDs.java - Merge Sort for patient registration IDs.
5. QuickSortFlightTicketPrices.java - Quick Sort using Lomuto partition for flight ticket prices.
6. CountingSortGenreCodes.java - Counting Sort for bounded genre codes 1..20.

How to run:
- javac *.java
- java MergeSortEmployeeSalaries
- java QuickSortFlightTicketPrices
- java CountingSortGenreCodes
